# Story fixtures

Media generated locally with ffmpeg, so stories and the browser gates play real
media with no network. Regenerate with the commands in
`docs/proposals/2026-10-02-media-text-and-recipe-parity.md` (appendix A).

| File | What it is |
|---|---|
| `harbour.mp4` | 8 s, 640×360 H.264 gradient, two AAC audio tracks (English 330 Hz, French 550 Hz). |
| `harbour.en.vtt`, `harbour.fr.vtt` | Captions in two languages, three cues each, one with italics. |
| `episode.m4a` | 8 s AAC tone pair for the audio player. |
